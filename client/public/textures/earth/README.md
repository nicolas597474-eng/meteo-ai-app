# Earth texture attribution

These five textures are vendored from the `examples/textures/planets` directory
of [three.js](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets).
Retrieved on 2026-10-13 via the GitHub contents API. No remote image service is
contacted by the application. They are used for the loading screen only.

- `earth_atmos_2048.jpg`: daytime surface
- `earth_normal_2048.jpg`: surface normal map
- `earth_specular_2048.jpg`: reflective oceans
- `earth_clouds_1024.png`: cloud coverage mask
- `earth_lights_2048.png`: nighttime city lights

The upstream three.js MIT license is reproduced in `LICENSE-three.txt`.
